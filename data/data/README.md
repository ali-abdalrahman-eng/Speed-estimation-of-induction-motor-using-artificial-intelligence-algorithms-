# Experimental Dataset

This directory contains empirical operational data—including two-phase voltages ($V_a, V_b$), two-phase currents ($I_a, I_b$), and rotor speed ($\omega_r$)—collected across four distinct operating points: frequency acceleration, frequency deceleration, applied mechanical load, and a randomized frequency regime combining all prior dynamics. The dataset is structured to evaluate and train the neural network model across a comprehensive spectrum of transient and steady-state operating conditions.
